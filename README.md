# 🚀 Current Projects

## 🛰️ Orion — AI Network Analytics Platform

An experimental network analytics platform focused on bringing together:

**Zeek + nDPI + Kafka + Python + FastAPI + Grafana + databases + local LLM/AI**

The goal is to explore how network traffic data can be collected, streamed, analyzed, visualized, and eventually enhanced with AI-assisted investigation.

---

## 📦 Enterprise Warehouse Management

A customized asset and warehouse management platform built around React and Node.

My work includes customization of the application, permissions, user experience, workflows, and enterprise-specific functionality.

---

## 🌐 Enterprise L2 Network Monitoring

A practical network monitoring and automation project designed around real enterprise switching environments.

The project includes:

- SNMP-based collection
- Switch and port monitoring
- SFP optical power collection
- UTP port status
- MySQL data storage
- Python automation
- Grafana visualization
- Scheduled network data collection

---

## 📡 GPON Optical Monitoring

Automation around GPON monitoring to collect optical information such as:

- CPE RX power
- CPE TX power
- Optical health information
- GPON / CPE operational data

The project explores browser automation, data extraction, Python processing, and visualization.
